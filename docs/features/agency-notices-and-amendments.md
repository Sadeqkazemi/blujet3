# اطلاعیه و اصلاحیه پنل آژانس

## دامنه

این صفحه سه منبع واقعی و مجزا را در یک مرکز اطلاع‌رسانی آژانس تجمیع می‌کند:

- اطلاعیه فعال پنل ادمین سایت از `GET /site-content/home` و بلوک `ANNOUNCEMENT_BAR`.
- پروازهای فعال و قابل درخواست آژانس از `GET /agency-portal/seat-request-options`.
- نوتیفیکیشن‌های مختص حساب آژانس از `GET /notifications`.

## چک‌لیست پذیرش

- [x] گزینه «اطلاعیه و اصلاحیه» در منوی دسکتاپ و موبایل پنل آژانس وجود دارد و مسیر `/agency/notices` را باز می‌کند.
- [x] عنوان و توضیح اطلاعیه‌ای که ادمین سایت در بلوک `ANNOUNCEMENT_BAR` فعال کرده، در صفحه آژانس نمایش داده می‌شود.
- [x] ادمین سایت می‌تواند علاوه بر عنوان، متن کامل/دستورالعمل اطلاعیه را در فیلد زیرعنوان وارد کند.
- [x] هر پرواز واقعی که برای درخواست صندلی آژانس منتشر و باز است، به‌صورت یک اطلاعیه مستقل نمایش داده می‌شود.
- [x] جزئیات پرواز شامل شماره پرواز، مسیر، زمان، هواپیما، کابین/کلاس نرخی، ظرفیت قابل درخواست و قیمت واقعی است.
- [x] نوتیفیکیشن‌های API فقط برای همان دریافت‌کننده آژانس نمایش داده می‌شوند.
- [x] کلیک روی هر ردیف، متن کامل را در پنجره جزئیات باز می‌کند.
- [x] باز کردن یک نوتیفیکیشن خوانده‌نشده، آن را از طریق `PATCH /notifications/:id/read` خوانده‌شده می‌کند.
- [x] فیلتر «همه»، «پروازها»، «اطلاعیه ادمین» و «نوتیفیکیشن‌ها» کار می‌کند.
- [x] حالت‌های بارگذاری، بدون داده، خطای کامل و خطای جزئی بدون ساخت داده نمایشی مدیریت می‌شوند.
- [x] صفحه در فارسی/انگلیسی/عربی و جهت صحیح RTL/LTR قابل استفاده است.
- [x] تست‌های کامپوننت، مسیر/منو، lint و build فرانت‌اند عبور می‌کنند.
