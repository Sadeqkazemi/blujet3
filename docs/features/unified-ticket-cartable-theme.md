# یکپارچه‌سازی تیکت‌ها در کارتابل و تم پنل‌ها

## هدف

مرکز تیکت باید در کارتابل مدیر ارشد، مدیرعامل، رئیس هیئت‌مدیره، مدیر بازرگانی، مدیر مالی، مدیر IT و کارمندان در دسترس باشد. نمایش تیکت در پنل مشتری و آژانس باید با تم روشن همان پنل هماهنگ باشد و تضاد رنگ یا متن ناخوانا نداشته باشد.

## معیارهای پذیرش

- [x] در مسیر کارتابل نقش‌های مدیریتی و کارمند، تب «تیکت‌های پشتیبانی» در کنار «کارتابل داخلی» دیده می‌شود.
- [x] نقش‌های مدیریتی مجاز می‌توانند تیکت‌های مشتری و آژانس را جستجو، ردیابی، مشاهده، پاسخ و مدیریت کنند.
- [x] کارمند فقط تیکت ارجاع‌شده به خودش را مشاهده می‌کند و می‌تواند در همان گفتگو پاسخ بدهد.
- [x] شماره تیکت، وضعیت، تاریخچه‌ی زمانی پیام‌ها و فایل‌های پیوست در کارتابل حفظ می‌شود.
- [x] مرکز تیکت مشتری و آژانس با تم روشن، متن تیره، مرزهای خوانا و وضعیت‌های رنگی هماهنگ نمایش داده می‌شود.
- [x] مرکز تیکت مدیریتی با تم تیره‌ی پنل مدیریت هماهنگ باقی می‌ماند.
- [x] چیدمان فهرست و گفتگو در موبایل و دسکتاپ بدون خروج افقی ناخواسته قابل استفاده است.
- [x] حالت‌های بارگذاری، خالی، خطا و تیکت بسته‌شده پیام واضح دارند.

## آزمون‌های رگرسیون

- [x] تست کامپوننت تم روشن/تیره‌ی مرکز گفتگو.
- [x] تست مسیریاب کارتابل برای نمایش تب تیکت به مدیر و کارمند.
- [x] تست نقش‌های مجاز API و محدودسازی تیکت‌های کارمند به ارجاع‌های خودش.
- [x] اجرای تست‌های هدفمند frontend/backend، lint، typecheck و build.
