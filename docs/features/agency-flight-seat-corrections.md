# اصلاح ظرفیت فروش و پنل صندلی آژانس — ۱۴۰۵/۰۶/۰۴

## معیارهای پذیرش

- [x] آزادسازی ظرفیت و قیمت فروش آژانسی و کنترل فروش سایت فقط در تب
  «اطلاعات و فروش» جزئیات پرواز فعال نمایش داده و از همان‌جا ذخیره می‌شود.
- [x] ظرفیت آزادشده برای هر کلاس از ظرفیت مصوب همان کلاس بیشتر نمی‌شود و
  مجموع فروش/تعهد/تخصیص از ظرفیت مصوب مدیر بازرگانی عبور نمی‌کند.
- [x] تب «پروازهای فعال» آژانس فقط سهمیه‌های پرداخت‌شده و تخصیص‌یافته به همان
  آژانس را با تعداد تخصیص‌یافته، فروخته‌شده و باقی‌مانده نشان می‌دهد؛ پرواز
  صرفاً قابل‌درخواست در این تب نمایش داده نمی‌شود.
- [x] در «مسیر پروازهای موجود» هر شماره پرواز/کابین/کلاس یک کارت مستقل دارد و
  فرم استعلام داخل همان کارت انتخاب‌شده باز می‌شود.
- [x] فرم استعلام شامل تعداد صندلی، پاسخ واقعی API رزرواسیون، تأیید، ماه‌ها و
  روزهای واقعی رخدادهای تأییدشده پرواز است.
- [x] پروفایل آژانس بخش «مدارک ارسالی» و «افزودن مدرک» دارد؛ PDF/JPG/PNG از
  سیستم کاربر آپلود و نتیجه در فهرست مدارک همان آژانس نمایش داده می‌شود.
- [x] در جستجوی پرواز داخلی فقط فرودگاه‌های ایران و در جستجوی خارجی فقط
  فرودگاه‌های بین‌المللی ایران به‌همراه همه فرودگاه‌های خارج ایران نمایش داده
  می‌شوند؛ این قانون در صفحه اصلی و خرید بلیت آژانس یکسان است.
- [x] در انتخاب ساعت پرواز، ستون ساعت سمت چپ و ستون دقیقه سمت راست است و مقدار
  ذخیره‌شده همچنان `HH:mm` بیست‌وچهارساعته باقی می‌ماند.
- [x] تعداد صندلی باقی‌مانده در نتایج و جزئیات عمومی از ظرفیت مصوب کلاس‌های
  نرخی مدیر بازرگانی محاسبه می‌شود و از ظرفیت فیزیکی هواپیما بیشتر نیست.
