# حذف استرداد از خدمات پنل بازرگانی

## دامنه

این تغییر فقط فهرست «خدمات جانبی پروازی» در پنل مدیر بازرگانی و کارکنان مجاز
بازرگانی را اصلاح می‌کند. جریان ثبت و پرداخت استرداد، قوانین نرخ و پنل مالی در
دامنه این تغییر نیستند.
