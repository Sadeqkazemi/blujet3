# بازطراحی فروش و گزارش‌های پنل آژانس — RTRD / PSR / PRR

## مرجع تصویری

چهار تصویر ارائه‌شده ساختار «جزئیات گزارش فروش» را مشخص می‌کنند: سربرگ مشخصات دوره و آژانس، شمارنده فروش/اصلاح/استرداد و سه تب `RTRD`، `PSR` و `PRR`.

## منبع داده

- `GET /agency-portal/sales`: فروش‌ها، PNR، پرواز، مسیر، کلاس، مبلغ و وضعیت واقعی همان آژانس.
- `GET /agency-portal/profile`: نام و کد/مجوز واقعی آژانس.
- `GET /agency-portal/credit`: سقف، مصرف و مانده واقعی اعتبار.
- `GET /agency-portal/invoices`: مبالغ پرداخت‌شده و قابل پرداخت واقعی.
- `GET /agency-portal/sales/export`: خروجی CSV واقعی موجود.

## محدودیت صادقانه داده

مدل فعلی آژانس کرایه را به مالیات، CRCN، کمیسیون و هزینه اصلاح تفکیک نمی‌کند و شماره بلیط الکترونیکی جداگانه ندارد. این ستون‌ها با خط تیره/«ثبت نشده» نمایش داده می‌شوند؛ هیچ عدد نمونه‌ای از تصاویر وارد محصول نمی‌شود. وقتی این اجزا در دفتر مالی ثبت شوند، قرارداد API باید به‌صورت جداگانه توسعه یابد.
