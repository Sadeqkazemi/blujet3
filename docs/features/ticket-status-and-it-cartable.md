# فیلتر وضعیت تیکت و کارتابل مدیر IT

## معیارهای پذیرش

- [x] کارت‌های «همه»، «باز»، «در حال بررسی»، «پاسخ داده‌شده» و «بسته‌شده» دکمه قابل انتخاب هستند و جدول را فیلتر می‌کنند.
- [x] تب‌های وضعیت و کارت‌های KPI یک state مشترک دارند و وضعیت فعال برای کاربر مشخص است.
- [x] جستجوی شماره/موضوع/درخواست‌کننده هم‌زمان با فیلتر وضعیت کار می‌کند.
- [x] کارتابل داخلی وضعیت‌های باز، تأییدشده، ردشده و منتقل‌شده را از API فیلتر می‌کند و شمارنده وضعیت‌ها را نمایش می‌دهد.
- [x] مدیر IT همان پوسته تیره و منظم کارتابل سایر مدیران را می‌بیند.
- [x] تست رابط برای کلیک کارت وضعیت تیکت، فیلتر کارتابل و پوسته مدیر IT وجود دارد.
