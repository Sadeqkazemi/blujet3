# هم‌راستاسازی موجودی فروش، پیوست پیام و کلاس‌های هواپیما

## هدف

این تغییر منبع نمایش و فروش صندلی سایت و آژانس را به آزادسازی مدیر بازرگانی
متصل می‌کند، پیوست سند را در همه مسیرهای پیام خواسته‌شده یکسان می‌کند و کلاس‌های
قابل استفاده پرواز را از کابین‌های تعریف‌شده برای هواپیمای همان پرواز می‌گیرد.
