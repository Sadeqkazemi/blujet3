# موتور گزارش فروش مدیر مالی — نسخه ۲

## مبنا

فایل `Blujet_Sales_Report_Template (2).xlsx` به‌عنوان مرجع فیلدها، فیلترها، گزارش تفصیلی و خلاصه فروش بررسی شد. قالب ظاهری نهایی خروجی بعداً از سوی مالک محصول ارائه می‌شود؛ بنابراین این فاز روی صحت داده، فیلتر و سه فرمت خروجی متمرکز است.

## معیارهای پذیرش

- [x] تجمیع و فیلتر گزارش فقط در سرور انجام می‌شود و رابط داده نمونه تولید نمی‌کند.
- [x] بازه رزرو/پرواز، وضعیت رزرو، وضعیت پرداخت، مبدأ، مقصد، کلاس کابین، کانال فروش و آژانس قابل فیلتر است.
- [x] پیش‌نمایش گزارش شامل KPIهای تعداد سفارش، تعداد مسافر، فروش ناخالص، درآمد خالص و میانگین ارزش سفارش است.
- [x] گزارش تفصیلی حداقل شناسه سفارش، PNR، تاریخ رزرو، وضعیت، کانال، پرواز، مسیر، زمان پرواز، کلاس، تعداد مسافر، مبلغ پایه، مالیات، خدمات جانبی، مبلغ کل و وضعیت پرداخت را برمی‌گرداند.
- [x] همان نتیجه فیلترشده به CSV، Excel و PDF خلاصه صادر می‌شود.
- [x] مجوز `rp_finance` و نقش مدیر مالی/کارمند مجاز روی همه endpointها اعمال می‌شود.
- [x] تست واحد برای فیلترها و هر سه فرمت خروجی وجود دارد.
- [x] جستجوی پرواز بدون عبارت اجرا نمی‌شود، حداقل دو نویسه می‌خواهد، حداکثر ۲۰ نتیجه را در API می‌پذیرد و رابط فقط ۶ ردیف در هر صفحه نشان می‌دهد.
- [x] تقویم شمسی با فاصله صحیح روزهای ابتدای ماه و شروع هفته از شنبه نمایش داده می‌شود.
- [x] URL دانلود تا پایان شروع دانلود مرورگر معتبر می‌ماند؛ فایل XLSX تولیدشده با ابزار مستقل بازخوانی و هر ۸ شیت آن تأیید شده است.
- [x] خرابی یک endpoint در گزارش تحلیلی، کل صفحه مالی را مخفی نمی‌کند و اطلاعات سالم همراه هشدار بخش ناقص نمایش داده می‌شود.
